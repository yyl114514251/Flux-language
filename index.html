Flux 语法速查

  
表达式优先、管道流动、空值安全、默认不可变。花括号 { } 分块。

  
变量
let x = 10     // 不可变（赋值会报错）
var y = 20     // 可变
y = 30         // OK

  
管道 |>（核心特色）
[1,2,3,4,5]
  |> fn(arr) { arr.filter(fn(x) { x > 2 }) }
  |> fn(arr) { arr.map(fn(x) { x * x }) }
  |> fn(arr) { arr.reduce(fn(a,b) { a+b }, 0) }
// 结果: 9 + 16 + 25 = 50

  
表达式 if / match
let g = if score >= 90 { "A" } else { "B" }
let r = match color {
  "red"   => { 1 }
  "green" => { 2 }
  _       => { 0 }
}

  
函数
fn add(a, b) { return a + b }
let sq = fn(x) => x * x     // 箭头函数
add(2, 3)  // 5
sq(7)     // 49

  
范围与循环
for i in 1..5 { print(i) }    // 1 2 3 4（不含5）
for i in 1..=5 { print(i) }   // 1 2 3 4 5（含5）
for i in 1..<5 { print(i) }   // 1 2 3 4（排除上界）
while cond { ... }
break / continue

  
空值安全
let v = obj?.name        // obj 为 null 时返回 null
let d = v ?? "默认值"    // v 为 null 时取默认值

  
字符串插值
let name = "World"
print(f"Hello, ${name}! 1+1=${1+1}")

  
断言
assert 1 + 1 == 2
assert sorted[0] == 11, "最小值应该是11"
